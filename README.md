# 🎬 OTT Platform - Core Java

A console-based OTT Platform developed using Core Java. This project simulates the basic functionalities of an online streaming platform, allowing users to browse movies, manage accounts, and interact with content through a simple command-line interface.

## 🚀 Features

* User Registration
* User Login Authentication
* View Available Movies
* Search Movies
* Movie Categorization
* Watchlist Management
* Menu-Driven Console Application
* Object-Oriented Programming Concepts

## 🛠️ Technologies Used

* Java
* Core Java
* Collections Framework
* Exception Handling
* OOP Principles
* File Handling (if implemented)

## ⚙️ How to Run

### Clone the Repository

```bash
git clone https://github.com/Vijay234M/OTT-Platform.git
cd OTT-Platform
```

### Compile the Project

```bash
javac *.java
```

### Run the Application

```bash
java Main
```
